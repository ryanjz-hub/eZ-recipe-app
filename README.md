# eZ Recipes

An 7-page responsive web application built as an academic project to establish foundational skills in front-end web development, semantic markup, and CSS layout architecture.

## Overview
This project was developed to learn the core principles of web design without relying on third-party frameworks or libraries. It explores multi-page site structure, navigation consistency, asset linking, and responsive UI design using native web standards.

## Built With
- HTML5: Semantic document structuring, media embedding, and multi-page linking
- CSS3: Flexbox layouts, button interactions, custom web typography, and custom styling
- GitHub Pages: Static site hosting and source code version control

## Pages and Content
- About: Background, project motivation, and food culture introduction
- Western Fast Food: Popular fast-food copycat recipes including Big Mac sauce and milkshakes
- Chinese Cuisine: Traditional Cantonese recipes including Char Siu and baked tapioca pudding
- Media: Step-by-step video tutorials and instructional preparation guides
